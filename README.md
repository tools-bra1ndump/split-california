# Split California Map

Static GitHub Pages site for the "Divide California" and "Two Californias" map.

- `california-interactive-map.jsx` is the React map component.
- `app/src/main.jsx` mounts the component for Vite.
- `index.html` and `assets/` are the built GitHub Pages output at repo root.

Build locally:

```sh
npm install
npm run build
```
